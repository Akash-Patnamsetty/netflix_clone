# Netflix Clone Website 🎬

A responsive Netflix-inspired frontend web application built using **HTML, CSS, and JavaScript** in a single HTML file.

This project recreates the modern Netflix user interface with movie banners, interactive cards, hover effects, and trailer playback functionality.

---

## 🚀 Features

- Netflix-inspired modern UI
- Fully responsive design
- Interactive movie cards
- Trailer playback functionality
- Hero banner section
- Smooth hover animations
- Responsive navigation bar
- Mobile-friendly layout
- Single file implementation

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Internal CSS)
- JavaScript (Internal JS)
